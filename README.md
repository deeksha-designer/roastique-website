# Roastique — Preview 1

Static, responsive homepage prototype based on the supplied proposal, strict Roastique palette and the approved 14-section flow.

## Run locally

Open `index.html` directly, or serve this folder with any static server. No build step or package installation is required.

## Files

- `index.html` — semantic homepage and all 13 approved content sections
- `styles.css` — token-led design system, layout, responsive rules and reduced-motion handling
- `app.js` — sticky header state and the AI Sommelier mood interaction
- `DESIGN_SYSTEM.md` — implementation contract for consistent future Codex work

## Content status

The prototype intentionally marks unconfirmed operational facts, partner logos and sample menu content. Replace them only with approved client inputs. Current imagery is directional stock photography and should be replaced with commissioned Roastique photography before production.
